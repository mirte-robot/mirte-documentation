       ..

       Use the M3 x 12 screw to fix the motor. Make sure to use the
       three holes as shown otherwise the screw will block the
       gearbox.

   .. figure:: _images/build_instructions/base_step_3.jpg
   .. figure:: _images/build_instructions/base_step_4.jpg
   .. figure:: _images/build_instructions/base_step_5.jpg

       ..

       Slide the motors in place. Make sure the orientation of the plate
       is correct, by looking at the holes of the PCB (blue) and OrangePi 
       (red). Use the M4 x 16 screws and M4 locknut to tighten the motors.

   .. figure:: _images/build_instructions/base_step_6.jpg

       ..

       Use the M2.5 standoff and M2.5 x 6 screws (with washer and spring
       washer).

   .. figure:: _images/build_instructions/base_step_7.jpg

       ..

       Use the 25mm M4 standoff and M4 x 16 screws (with washer and spring
       washer).

   .. figure:: _images/build_instructions/base_step_8.jpg
   .. figure:: _images/build_instructions/base_step_9.jpg

       ..

       Attach the 30cm JST PH cable to the rear motors.      

   .. figure:: _images/build_instructions/base_step_10.jpg 
   .. figure:: _images/build_instructions/base_step_11.jpg

       ..

       Attach the 20cm JST PH cable to the front motors. 

   .. figure:: _images/build_instructions/base_step_12.jpg

       ..

       Add the PCB using M4 x 16 screws (with spring washers). 

   .. figure:: _images/build_instructions/base_step_13.jpg
   .. figure:: _images/build_instructions/base_step_14.jpg

       ..

       Attach the M4 U-clip captive nut to the side plate. 

   .. figure:: _images/build_instructions/base_step_15.jpg
   .. figure:: _images/build_instructions/base_step_16.jpg
   .. figure:: _images/build_instructions/base_step_17.jpg

       ..

       Attach the 20cm JST XH cable to the oled (notice the orientation). 

   .. figure:: _images/build_instructions/base_step_18.jpg

       ..

       And slide the oled into the side plate. 

   .. figure:: _images/build_instructions/base_step_19.jpg

       ..

       Use M4 x 16 screws to attach the side plate to the bottom plate. 

   .. figure:: _images/build_instructions/base_step_20.jpg
   .. figure:: _images/build_instructions/base_step_21.jpg

       ..

       Connect the JST cables of the motors and the oled. 

   .. figure:: _images/build_instructions/base_step_22.jpg

       ..

       Take the hexagon ring of the switch and attach the button to the
       side panel. 

   .. figure:: _images/build_instructions/base_step_23.jpg
   .. figure:: _images/build_instructions/base_step_24.jpg
   .. figure:: _images/build_instructions/base_step_25.jpg

       ..

       Add the EMMC to the Orange Pi. 

   .. figure:: _images/build_instructions/base_step_26.jpg
        
       ..

       Use M2.5 x 6 screws (with washer and spring washer) to place the
       Orange Pi. 

   .. figure:: _images/build_instructions/base_step_27.jpg

       ..

       You might need to loosen the M4 screws of the side panel a bit
       to correctly place the Orange Pi. 

   .. figure:: _images/build_instructions/base_step_28.jpg

       ..

       Attach the M4 U-clip captive nut to the side plate. 

   .. figure:: _images/build_instructions/base_step_29.jpg

       ..

       Attach the ethernet extension cable using M3 x 6 screws. 

   .. figure:: _images/build_instructions/base_step_30.jpg

       ..

       Use M4 x 16 screws to attach the side plate to the bottom plate.  

   .. figure:: _images/build_instructions/base_step_31.jpg
   .. figure:: _images/build_instructions/base_step_32.jpg

       ..

       Attach the M4 U-clip captive nut to the ultrasonic modules.  

   .. figure:: _images/build_instructions/base_step_33.jpg

       ..

       Connect the 30cm JST cables to the sensors (notice the orientation), and
       place them in the modules.  

   .. figure:: _images/build_instructions/base_step_34.jpg
        
       ..

       Use M4 x 16 screws to attach the modules to the base plate.  

   .. figure:: _images/build_instructions/base_step_35.jpg

       ..

       Dismount the screws on the bottom of the battery.  

   .. figure:: _images/build_instructions/base_step_36.jpg
   .. figure:: _images/build_instructions/base_step_37.jpg
        
       ..

       Use M3 x 16 screws to attach the battery module to the battery.  

   .. figure:: _images/build_instructions/base_step_38.jpg
   .. figure:: _images/build_instructions/base_step_39.jpg

       ..

       Attach the M4 U-clip captive nut to the ultrasonic modules.  

   .. figure:: _images/build_instructions/base_step_41.jpg

       ..

       Use 3 of the M2.5 x 6 screws to attacht the lidar.  

   .. figure:: _images/build_instructions/base_step_42.jpg
        
       ..

       Use the last M2.5 x 6 screws to attacht uart-board to the lidar.
